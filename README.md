# Visual Motion Lab v1

**公開アプリ：[Visual Motion Lab](https://kkodamalab.github.io/visual-motion-lab/)**

Chrome / EdgeでURLを開いて利用できます。ソースをダウンロードすればオフラインでも動作します。

大学授業用の、視覚運動・自己運動感覚・視覚による姿勢制御のデモです。外部ライブラリ、ネット接続、サーバーは不要です。

## 起動方法

1. `index.html` をChromeまたはEdgeで開きます（ダブルクリック、またはブラウザにドラッグ）。
2. 初回表示の注意事項を確認します。
3. Presetを選び、必要なら設定を調整します。
4. **FULLSCREEN → START → Hide controls** で提示します。カウントダウンは初期状態でONです。
5. **Esc** で停止して設定を表示します。全画面を抜けるときも停止します。

通常のファイル閲覧として実行します。インストールやブラウザの権限変更は不要です。FULLSCREENが使えない環境ではF11も利用できます。

### 操作

| 操作 | 動作 |
|---|---|
| START | 現在の状態から開始・再開。ONなら3、2、1の後に動く |
| STOP | 現在のドット位置・位相・経過時間で静止。カウントダウンも解除 |
| Space | 再生／停止の切替。カウントダウン中は中断。長押しの連続切替は無効。数値・選択欄などの入力中と注意ダイアログ表示中は対象外 |
| RESET | 停止し、設定を保持して時間・位相を0に戻し、同じ初期ドット配置を再生成 |
| FULLSCREEN | 文書全体の全画面表示を切替 |
| Hide / Show controls、H | 設定と状態表示を隠す・戻す。刺激の座標系は変わらない |
| Esc | 刺激・カウントダウンを停止して設定表示へ。ブラウザは全画面を解除する場合もある |
| Preset | 停止し、外観も含め既定の条件に置換。カウントダウンのON/OFFは保持 |

設定非表示時も左上に小さなShow controlsボタンが残ります。右上へポインターを動かすか、Tabでフォーカスすると操作ボタンが現れます。画面のほぼ全域を刺激に使いますが、完全にUIのない実験用提示ではありません。

タブが非表示になったとき、ウィンドウのフォーカスが外れたとき、全画面を終了したとき、描画の間隔が250 msを超えたときは停止します。画面サイズ変更時は初期配置・位相・時間をリセットします（提示中ならそのまま新しい配置で継続）。画面サイズと全画面を先に決めてから試行してください。

## 安全な授業運用

**気分が悪くなった場合は直ちに画面から目を離し、刺激提示を停止してください。**

初めは座位で短時間・低速から観察します。参加・中断は自由とし、症状が出た人に継続を求めないでください。立位の体験は教員の監督下で、周囲を片付け、支えを確保して行ってください。UI上限は過大な設定を避けるための設計値で、安全性を保証する閾値ではありません。

## 各刺激モードの意味

### 1. 2D dot motion

方向・パターンに9種類あります：左、右、上、下、拡大、収縮、左右周期、上下周期、拡大／収縮周期。

- **平行移動 / Constant**：`q(t) = d × v × t`。全点が同じ画面速度で動きます。`d`は方向の符号。右・下を正とし、左・上を負とします。位置を画面幅・高さの剰余で循環させ、端にまたがる図形も反対側に描くため、自然に再出現します。
- **平行移動 / Sinusoidal**：`q(t) = d × A sin(2πft)`。Aは片振幅、往復幅は2A、最大速度は`2πfA`です。速度に正弦波を掛けるのではなく、位置を正弦波で変えます。左右・上下の周期パターンは正方向から始まり、方向の左・上を選んでSinusoidalにすると初期方向が反転します。
- **2D optic expansion / contraction / Constant**：中央からのベクトルを`r(t+Δt) = r(t) exp(dkΔt)`で変化させます。速度は`dr/dt = dk r`。同じ偏心距離の点は同じ速度になり、奥行きによる差はありません。半径2 pxと画面対角半径の外側との間で点を再循環します。密度は時間とともに変化し、中心付近への集積や再出現を伴います。
- **2D expansion / contraction / Sinusoidal**：`r(t) = r₀ exp[d a sin(2πft)]`。対数倍率を正弦波にすることで倍率が常に正になります。倍率の範囲は`exp(-a)`〜`exp(a)`。同じ点が1周期で元の位置へ戻ります。画面より広い領域に点を生成して拡大縮小し、外側をクリップするため、表示中の点数は変化します。

周期パターンを選ぶとSinusoidalに、単方向パターンを選ぶとConstantになります。単方向パターンでもMotion typeをSinusoidalに変更できます。周期パターンでConstantを選ぶと右・下・拡大の対応する単方向パターンへ移ります。

### 2. Visual push

画面全体を覆う平行移動の専用モードです。左右・上下について一定速度または正弦波変位を選択できます。計算は2D平行移動と同じです。

画面上の運動、感じられる自己運動、姿勢の反応を別々に考察します。設定の方向は**ドットが動く方向**です。自己運動の感じ方や身体の反応方向・大きさを指定する値ではありません。

### 3. 3D optic flow

各点に仮想3D座標`(X, Y, Z)`を保持し、ピンホールカメラによる透視投影を行います。

```text
F = screenWidth / [2 tan(horizontalFOV / 2)]
x = FOE_X + F X / Z
y = FOE_Y + F Y / Z

前進：Z(t+Δt) = Z(t) − v Δt
後退：Z(t+Δt) = Z(t) + v Δt
周期：観察者変位 C(t) = d A sin(2πft)
      Z(t+Δt) = Z(t) − [C(t+Δt) − C(t)]
```

正面を向いてマウス操作をしていない場合、投影点の速度は前進時に`dx/dt = (x−FOE_X) v/Z`、`dy/dt = (y−FOE_Y) v/Z`です。同じ画面上の偏心距離でも近い点ほど速く流れます。これは全点を一律に拡大する2Dモードとの違いです。前進はFOEからの拡大、後退は同じ位置への収縮を生みます。FOE X/Y設定は投影中心の移動です。マウスによる視線回転を加えると、以下のように流れが変わります。

### マウスで視点を変える

2D／Visual pushの「マウスで3D探索」ボタンを押すと、外観設定を保ったまま3D・自動速度0に切り替わります。SpaceまたはSTARTで再生してください。既存のForward／Backward Presetでもマウス操作を使えます。

- **刺激領域を左ドラッグ**：右へ動かすと視線が右、下へ動かすと視線が下を向きます。ドット像は反対側へ流れます。左右±60°、上下±45°、0.12°/px、回転速度最大30°/sです。急な操作には滑らかに追従します。
- **ホイール上／下**：現在の視線方向へ前進／後退します。ズームではなく3Dの並進なので、奥行きによって流れが異なります。ホイール量を換算した100 pxあたり0.2 m、未処理移動量±0.5 m、速度最大2 m/sです。
- **自動運動との関係**：自動の前後移動軸は初期の世界Z軸に固定しています。横を向くと、その進行方向の投影位置がずれ、流れの方向も変わります。回転中には回転による流れが重なります。このときFOE X/Yの値は投影中心であり、自動並進のFOEそのものとは一致しません。
- **停止と初期化**：Space／STOP／Escは自動運動と手動操作を停止し、残った操作量を破棄します。停止・カウントダウン中はマウスで刺激を動かせません。「視点を正面へ戻す」は停止して正面・同じ初期配置へ戻します。RESET、Preset、運動条件変更でも視点を初期化します。
- **操作の有効範囲**：3Dモードかつ「マウスで視点を操作」がONのときに有効です。設定パネル上のドラッグ・ホイールは通常のUI操作となります。Ctrl＋ホイールはブラウザに任せます。2Dの刺激条件を比較する場合は、従来どおりマウスが刺激を変えません。

実装では点を視線回転の逆行列でカメラ座標に変換して透視投影します。near/farはカメラ座標の深度に適用し、再生成点も現在のカメラ座標から世界座標へ逆変換します。手動並進では世界座標のX/Yも変化します。表示される「手動の前後移動」は符号付き移動量の累計であり、3D位置ベクトルや原点からの直線距離ではありません。手動の操作履歴は保存しないため、同じPresetだけでは手動試行を再現できません。

**点の生成と限界：**画面上の位置とnear〜farの深度をそれぞれ一様乱数で選び、逆投影して3D座標を生成します。奥行き範囲または画面から外れた点は再生成します。自動並進だけの場合、その間はX・Yを固定しZだけを変えます。ただし再生成は密度維持のための処理で、無限の一様な3D体積を通過するシミュレーションではありません。周期運動では再生成された点まで厳密に元の位置へ戻るわけではありません。点の直径は奥行きで変えず、全て一定の画面サイズです。両眼視差、頭部追跡、実空間への校正はありません。

FOVは仮想カメラの水平画角です。初期画面密度を保つため、FOV変更時にはその画角に合わせて3D点を再生成します。この軸方向並進・画面一様サンプリングでは、FOVが変わっても見かけの流れの統計はほぼ変わりません。FOVは実際の投影面の大きさや観察距離を自動設定しません。

## 各パラメータの意味

| パラメータ | 範囲 | 意味 |
|---|---|---|
| 背景色・ドット色 | カラーピッカー | 任意のRGB色 |
| ドット形状 | 円・四角・十字・短い水平線 | 円の直径、他の形の外形幅をサイズで指定 |
| ドットサイズ | 1〜16 CSS px | 画面上の径／幅。十字・線の太さは幅の1/5、最小1 px |
| ドット数 / density | 100〜4000 | 生成する点数。面積や立体角あたりの密度ではない。クリップ・重なりによって見える個数は少なくなる |
| 不透明度 | 0.05〜1 | 1が不透明。透明度は1−不透明度 |
| Speed | 0〜200 px/s | 2D平行移動の一定速度 |
| Amplitude | 0〜80 px | 2D平行移動の片振幅 |
| Expansion rate | 0〜0.5 s⁻¹ | 2D一定拡大・収縮の相対変化率k |
| Amplitude（対数倍率） | 0〜0.35 | 2D放射状周期運動のa。最大で約0.70〜1.42倍 |
| Simulated speed | 0〜2 m/s | 3D一定前進／後退の仮想速度 |
| Amplitude（前後変位） | 0〜0.5 m | 3D周期運動の観察者の片振幅 |
| Frequency | 0.05〜0.5 Hz | 正弦波の周期の逆数。0.15 Hzなら約6.67秒/周期 |
| Depth near | 1〜10 m | 近側クリップ面 |
| Depth far | 2〜50 m | 遠側クリップ面。nearより最低1 m遠くなるよう制限 |
| Field of view | 40〜120° | 仮想カメラの水平画角 |
| FOE X / Y | 10〜90% | 左端・上端を0%、右端・下端を100%とした投影中心 |

使うパラメータだけを表示します。**SinusoidalではSpeedは使わず、AmplitudeとFrequencyで速度が決まります。** UIに最大速度を表示します。2D平行移動のUI上限の組合せでは約251 px/sです。

外観の色・形・サイズ・不透明度は運動を継続したまま変更できます。速度・振幅・周波数・ドット数・モード・投影パラメータは即時反映しますが、初期配置と位相をリセットします。連続した条件比較には試行を区切ってください。スライダーの隣の数値欄も編集できます。

CSS pxは物理的なmmや視角のdegreeとは異なります。3Dのmも仮想空間上の単位です。物理画面幅W、観察距離Dが分かれば、実際の水平視野角は`2 atan(W/(2D))`で計算できます。同じpx/sでもモニター寸法、表示倍率、観察距離によって網膜上の速度は異なります。

## 授業での使用例

1. **導入**：自己の動きでも外界の動きでも網膜像が動くこと、視覚が身体と環境の相対運動の手掛かりになることを説明します。
2. **座位で静止基準**：Static dotsを短時間観察し、感じたことを記録します。
3. **Visual push**：Slowから始め、左右を比較します。「点が動く方向」「自分が動いたように感じる方向」を分けて回答してもらいます。Fastは必要に応じて使います。
4. **周期運動**：Swinging-room-likeを2〜3周期程度観察します。振幅だけ、次に周波数だけ変えます。ただし周波数を変えると最大速度も変わることを確認します。
5. **奥行きの流れ**：ForwardとBackwardを比較します。FOEから離れる／近づく方向、同じ偏心距離でも速度が異なる点に注目します。2D拡大との違いも比較します。
6. **振り返り**：自己運動感覚の有無・強さと、感じた身体の揺れを別々に記録します。感じない学生の回答もそのまま扱います。

教室での主観報告だけから、姿勢制御の変化が客観的に実証されたとは結論づけません。姿勢の変化を検討する場合は別途、重心動揺や身体運動の計測が必要です。また単眼の平面スクリーンは物理的に動く壁・天井を含むSwinging Roomとは異なります。

### 理論的背景・参考文献

## ファイル構成と変更方法

```text
visual-motion-lab/
  .nojekyll    GitHub Pagesの静的配信設定
  index.html   HTML / CSS / JavaScriptを全て含むアプリ本体
  README.md    この説明書
```

教員が変更する場合は、index.htmlをテキストエディタで開いてください。

- `DEFAULTS`：共通の初期値。
- `PRESETS`：Preset名・補足文・上書きする値。
- `buildRanges()`：UI範囲・刻み・単位。数値入力も同じ範囲に制限します。
- `advance(dt)`：フレーム間の経過秒に基づく運動計算。
- `spawn3D()` / `project()`：点の生成・透視投影。
- `draw()`：Canvas描画。点径は一定で、残像・自動的なカメラ揺れ等は加えていません。
- `seed=1975` / `rand()`：再現可能な乱数列。RESET時には同じ種に戻ります。

requestAnimationFrameと実経過秒によりフレームレートへの依存を避けます。HiDPI対応の描画倍率は性能のため最大2倍です。60 fps程度を目標にしていますが、ディスプレイの更新頻度・PC・投影環境に依存します。右下のfpsはrequestAnimationFrameの呼出頻度の概算で、光学的な提示時刻の検証値ではありません。低速になる場合は点数を減らしてください。研究用の厳密な時間精度・刺激校正・姿勢計測は本v1の対象外です。

### v1の検証

WindowsのChromeとEdgeをヘッドレス起動し、ローカルの`file:` URLで検証しました。7 Preset、開始・停止・リセット、カウントダウン完了と中断、Esc、設定非表示、Fullscreen API、深度範囲の制約を確認し、JavaScriptエラーはありませんでした。1440×1000と390×844のスクリーンショットで表示も確認しています。

数値検証では、9パターンの反復更新、正弦波の1周期後の復帰、3Dで近い点ほど大きい投影速度となること、前進・後退の符号、4000点でのクリップ・再生成、RESETによる同じ配置の再現を確認しました。実機プロジェクターでのfpsや、学生の自己運動感覚・姿勢への効果は未検証です。

マウス・Space追加後も上記を再検証しました。Chrome／EdgeでSpaceの切替・長押し抑制・カウントダウン中断、ドラッグによる回転、ホイールの前後移動、停止中の静止、正面への復帰を確認しています。カメラ回転と逆回転の整合性、視線変更後の投影・クリップ処理も数値検証しました。
